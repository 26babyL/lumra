    1. Error Alpine Template String
Error ini terjadi karena syntax template string tidak valid. Alpine menggunakan :style dengan cara yang berbeda. Seharusnya:
<!-- Salah: -->
<div :style="`width:${55 + i * 7}%;background:var(--color-bg)" class="h-2.5 rounded animate-pulse"></div>

<!-- Benar: -->
<div :style="{ width: `${55 + i * 7}%`, background: 'var(--color-bg)' }" class="h-2.5 rounded animate-pulse"></div>

3. Error 404 Avatar
Tambahkan avatar default di folder static:
<!-- Di base.html atau sidebar.html -->
<img src="{% static 'img/default-avatar.png' %}" 
     class="avatar-ring h-[26px] w-[26px]"
     alt="{{ user.get_full_name|default:user.username }}">

     Atau gunakan placeholder:
     <img src="https://placehold.co/52x52/10b981/ffffff?text={{ user.username|first|upper }}"
     class="avatar-ring h-[26px] w-[26px]"
     alt="{{ user.get_full_name|default:user.username }}">

     4. Perbaiki Template String Alpine
Cari semua instance :style dengan template string dan ubah ke format object:
<!-- Sebelum: -->
<div :style="`width:${55 + i * 7}%;background:var(--color-bg)" class="h-2.5 rounded animate-pulse"></div>

<!-- Sesudah: -->
<div :style="{ width: `${55 + i * 7}%`, background: 'var(--color-bg)' }" class="h-2.5 rounded animate-pulse"></div>

5. Cek Alpine Version
Error Alpine expression mungkin karena versi Alpine yang tidak kompatibel. Pastikan menggunakan Alpine 3.x:
<script src="https://cdn.jsdelivr.net/npm/alpinejs@3.13.3/dist/cdn.min.js" defer></script>
